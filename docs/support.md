# Support

This is a small personal project shared as-is, with no guaranteed support.

- **Bugs and questions about this app:** open an [issue](https://github.com/XtraChase/linkedin-auto-applier/issues). Please do not paste your resume, answers, API key or log files containing personal details.
- **The original project** this app was built on is [GodsScion/Auto_job_applier_linkedIn](https://github.com/GodsScion/Auto_job_applier_linkedIn). Its community and sponsorship links belong to its author, not to this fork.
- When something stops working, the cause is usually that LinkedIn changed its pages. Run `python health_check.py` (read-only) to see which part broke.
